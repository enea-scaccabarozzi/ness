title: "ness probe run"

---

## Usage

```text
ness probe run PATH [flags]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--json` |  | print one JSON object |

## Inherited flags

| Flag | Default | Description |
|---|---|---|
| `--ui string` | `auto` | renderer: auto, rich or plain (also NESS_UI) |
