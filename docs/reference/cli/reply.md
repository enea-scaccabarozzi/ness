---
title: "ness reply"
description: "Answer an item and dispose it in one step"
---

## Usage

```text
ness reply ITEM [flags]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--as string` | `resolved` | resolved \| declined \| deferred \| accepted \| returned \| withdrawn |
| `--body TEXT` |  | the answer TEXT, or @FILE |

## Inherited flags

| Flag | Default | Description |
|---|---|---|
| `--ui string` | `auto` | renderer: auto, rich or plain (also NESS_UI) |
