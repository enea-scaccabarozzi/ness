---
title: "ness stats"
description: "Tokens, context, compactions, tool bytes and cost of this project's sessions, from their transcripts"
---

## Usage

```text
ness stats [flags]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--by string` | `session` | group by session \| tier \| role \| rung \| tool |
| `--json` |  | print one JSON object |
| `--since WHEN` |  | only entries at or after WHEN: a date, an RFC 3339 time or a duration (7d) |

## Inherited flags

| Flag | Default | Description |
|---|---|---|
| `--ui string` | `auto` | renderer: auto, rich or plain (also NESS_UI) |
