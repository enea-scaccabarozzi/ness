---
title: "ness worker run"
description: "Run the worker in this terminal: one process per project, a pass every 5 s"
---

## Usage

```text
ness worker run [flags]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `--once` |  | run one pass and exit |

## Inherited flags

| Flag | Default | Description |
|---|---|---|
| `--ui string` | `auto` | renderer: auto, rich or plain (also NESS_UI) |
