# P5b Probes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A session starts probe files; the worker runs each probe's floor on its schedule, turns exit codes and the last line's `key=value` pairs into GREEN, RED, UNCLEAR or VACUOUS, wakes the owner with a request item carrying the scope and the capped, redacted evidence when the probe's `wake`, `confirm` and `sample` say so, posts floor state changes or verdicts through the notify channels per `notify`, stops at `once` and `window`, reloads edited files, pauses a probe whose owner is gone and moves ownership to the manager when the owner closes; `ness probe run|verdict|stop`, `ness status`, `ness doctor` and `ness close` show and keep all of that; the CLI exposes exactly the 16 commands and none of the removed flags.

**Architecture:** `internal/probe` is the file (flat `key: value` frontmatter, Go durations plus `d`, the `expect` grammar), the floor run through `shell.Runner` (P5a) and the state, evidence and redaction rules. The store gains migration 5 (`probes`, `items.probe`) and the probe queries. `internal/worker/probes.go` is the scheduler slot in `Worker.Pass` (R-WRK-060/061): due probes run before the pane visits so the wake's hint lands in the same pass; posting goes through `notify.Poster` (P5a). `internal/cli/probe.go` is `start|run|verdict|stop`; `status`, `doctor` and `close` learn probes; a `stats` stub completes the command surface until P6.

**Tech Stack:** Go 1.27 (mise), `modernc.org/sqlite`, cobra, testscript, `math/rand/v2` (seeded in tests), `crypto/sha256`. No new module dependency: the frontmatter is flat and hand-parsed.

**Spec:** `docs/superpowers/specs/2026-10-08-ness-v1-scope.md` (P5 row), `docs/design/ness-design.md` §4 (every active probe has a live owner), §5 "Features", §8 (probes), §16 #5 and #6, decisions D9–D12, D24, and the requirements in `docs/spec/probes.md` (PRB, all 49), plus the carry-ins `docs/spec/worker.md` R-WRK-060, R-WRK-061, `docs/spec/sessions.md` R-SESS-070, R-SESS-081, R-SESS-083, `docs/spec/doctor.md` R-DOC-015, `docs/spec/core-config.md` R-CFG-030, R-CFG-031. P5a (`2026-10-09-p5a-notify-contracts.md`) delivered the seams this plan uses: `shell.Runner`, `notify.Poster`, `requireFeature`, `Deps.Shell`.

## Global Constraints

- Everything of P5a's Global Constraints holds: external programs through `Deps.Exec`, floors and the command channel through `Deps.Shell` (`shell.Run` in production and in scripts over throwaway commands; a fake runner in the worker tests), HTTP through `Deps.Transport`; exit codes 0 ok, 1 problems (`probe run` with a non-GREEN state), 2 usage, 4 refused; a refusal writes nothing; every test names its ids; conventional commits; no push, no CI watch.
- The worker never starts an agent and never runs a probe scope headlessly (R-WRK-060, D10): the only effects of a due probe are a floor run, a store row, a wake item in the owner's inbox and a channel post.
- A probe without a live owner pauses, is shown red in `status`, is listed by `doctor`, and resumes only when a live session runs `ness probe start` on it (R-PRB-071, R-WRK-061).
- Evidence is the last 4,096 bytes of the floor's combined output after the values of every `[probes] redact_env` variable were replaced, everywhere it is stored, sent, posted or printed (R-PRB-039).
- Defaults: `jitter` 0, `confirm` 1, `timeout` 60 s, `wake` not-green, `sample` 0, `notify` none (R-PRB-080); durations are Go syntax plus `d` = 24 h (R-PRB-081).
- `ness integrate` never starts a probe or posts (R-SESS-100): nothing in `internal/session/integrate.go` imports `internal/probe` or `internal/notify`.
- No `time.Sleep` in tests; the scheduler keeps its state in the store (`next_run_at`) and the tests step the worker bench's clock; the only real waits are on floor processes in `probe`'s own tests (`shell.Run` with a timeout).
- Lint limits: `cyclop` and `funlen` defaults, 120 columns, no shadowed `err`.
- Migrations are append-only: this plan appends migration 5 after P5a's 4.

## Review Focus

1. **A probe file deleted or broken after `start`.** The worker logs it once, keeps the row active, re-reads it every minute and runs again when it parses; `status` shows `file error`. Pinned in Task 4 (`TestBrokenFileIsLoggedOnceAndRetried`).
2. **A floor whose last line mixes `key=value` pairs with other words** (`n=3 ok lag=10ms`). The pair parser keeps the pairs, ignores bare words, and a non-numeric value fails the condition (VACUOUS), never a panic. Pinned in Task 1 (`TestParseKVIgnoresBareTokens`).
3. **An `every` shorter than the pass interval** (`every: 1s`). A probe runs at most once per pass and its next run is scheduled from the run, so it can never spin inside one pass. Pinned in Task 4 (`TestShortEveryRunsOncePerPass`).
4. **`verdict` twice on the same wake.** The second is refused (the item is disposed) and posts nothing; the first verdict stands. Pinned in Task 7 (`probe_verdict.txtar`).
5. **A `window` shorter than `every`** (`window: 1h`, `every: 2h`). The final wake still arrives at the window's end, exactly once, with no floor run before it. Pinned in Task 5 (`TestWindowShorterThanEveryStillEnds`).

## Rulings

- **Frontmatter is flat `key: value` lines, parsed without a YAML library.** The §8 example is flat; a nested or multi-line value is refused naming the line. One dependency fewer; a probe that needs YAML structure has no such field anyway.
- **A wake is a request item the owner sends to itself**, with the probe's id in the item's new `probe` column: the inbox line reads `from <owner>` and the body's first line names the probe; `verdict` disposes it with the new `store.Dispose` (no reply item, because a reply would land in the owner's own inbox and wake it again).
- **`start` rules by path:** the caller already owns an active probe at that path → restart it (the window restarts unless `--keep-window`); a paused probe exists at that path → the caller adopts it (owner, active, window per `--keep-window`); otherwise a new probe. Two sessions starting the same path get two probes (R-PRB-084).
- **Evidence is redacted, then capped**: a secret can never survive as a fragment at the cut.
- **Pass order: heartbeat, retirement, probes, visits.** A wake created by the probe step is hinted by the visit of the same pass.
- **The scheduler is the store's `next_run_at`**: no timers in the worker, the bench's stepped clock tests every schedule rule; `jitter` and `sample` draw from `Probes.Rand` (`math/rand/v2`, seeded in tests, `rand.NewPCG(seed)` from the clock in production).
- **Floorless probes have no state**: every run wakes (R-PRB-030), `confirm` and `sample` do not apply, `notify: auto` behaves as `judged` (R-PRB-053), and `status` shows `-` for the state.
- **`notify: auto|judged` with the `notify` feature off, or naming a channel that is not configured, is refused by `probe start`** (fail loudly, D15) and by the worker when the file changes to say so (logged once, the probe keeps running without posts).
- **`needs-edit` stores the file hash at the verdict**: `status` shows the flag while the file's hash still equals it; the next run after an edit clears it.
- **A broken or missing probe file keeps its row active**: logged once per text, re-read every minute (12 passes), `status` shows `file error`; pausing is for a missing owner only.
- **The `stats` stub** registers `ness stats` refusing with `ness stats arrives with P6 (docs/spec/stats.md)` (exit 4) so the 16-command surface (R-CFG-030) is real and tested now; P6 replaces its `RunE`.
- **`probe run` opens no store** (R-PRB-063): it parses, runs the floor in the current checkout as the caller, prints the state and the evidence, and exits 0 only on GREEN; a floorless probe prints `no floor` and the scope and exits 0.
- **The owner's worktree is the floor's cwd and the probe file's root** (R-PRB-083): `<primary>/<owner.Worktree>`, or the primary checkout for an adopted root.

// Package probe is the probes feature (design §8): one Markdown file with frontmatter per
// probe, an optional floor command whose exit code and last line give a state, and the scope
// the woken agent judges. The worker schedules; the owner answers.
package probe

import (
	"bufio"
	"bytes"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"regexp"
	"slices"
	"strconv"
	"strings"
	"time"
)

// Accepted values (R-PRB-004, R-PRB-005) and fields (R-PRB-002).
var (
	Wakes    = []string{"never", "change", "red", "not-green", "always"}
	Notifies = []string{"none", "auto", "judged"}
	Fields   = []string{"every", "jitter", "once", "window", "floor", "expect", "confirm", "timeout",
		"wake", "sample", "notify", "channel"}
)

// Probe is one parsed probe file with the defaults applied (R-PRB-080).
type Probe struct {
	Path                           string
	Every, Jitter, Window, Timeout time.Duration
	Once                           bool
	Floor                          string
	Expect                         []Cond
	Confirm                        int
	Wake, Notify, Channel          string
	Sample                         float64
	Scope                          string
	Hash                           string
}

// Floorless reports a probe with no floor: a pure semantic check that wakes on every run.
func (p Probe) Floorless() bool { return p.Floor == "" }

// Hash identifies the file's content, for reloads and the needs-edit flag (R-PRB-061, R-PRB-065).
func Hash(data []byte) string {
	sum := sha256.Sum256(data)
	return hex.EncodeToString(sum[:])
}

var kvLine = regexp.MustCompile(`^([a-z]+):\s*(.*)$`)

// Parse reads a probe file: flat key: value frontmatter between --- lines, the body as the
// scope. Every refusal names the file (R-PRB-003, R-PRB-008); nothing panics (R-PRB-009).
func Parse(path string, data []byte) (Probe, error) {
	fields, body, err := frontmatter(data)
	if err != nil {
		return Probe{}, fmt.Errorf("%s: %w", path, err)
	}
	p := Probe{Path: path, Confirm: 1, Timeout: 60 * time.Second, Wake: "not-green", Notify: "none",
		Scope: strings.TrimSpace(body), Hash: Hash(data)}
	for _, k := range slices.Sorted(maps.Keys(fields)) {
		if !slices.Contains(Fields, k) {
			return Probe{}, fmt.Errorf("%s: unknown field %s", path, k)
		}
		if err = p.set(k, fields[k]); err != nil {
			return Probe{}, fmt.Errorf("%s: %w", path, err)
		}
	}
	if err = p.check(); err != nil {
		return Probe{}, fmt.Errorf("%s: %w", path, err)
	}
	return p, nil
}

// frontmatter splits the --- block into key: value pairs (comments after # dropped, quotes
// stripped) and the body; a line that is not a flat pair is refused by number.
func frontmatter(data []byte) (map[string]string, string, error) {
	sc := bufio.NewScanner(bytes.NewReader(data))
	sc.Buffer(make([]byte, 0, 64*1024), 1<<20)
	if !sc.Scan() || strings.TrimSpace(sc.Text()) != "---" {
		return nil, "", errors.New("no frontmatter: the file must start with ---")
	}
	fields := map[string]string{}
	for n := 2; sc.Scan(); n++ {
		line := sc.Text()
		if strings.TrimSpace(line) == "---" {
			var body strings.Builder
			for sc.Scan() {
				body.WriteString(sc.Text())
				body.WriteByte('\n')
			}
			return fields, body.String(), sc.Err()
		}
		if strings.TrimSpace(line) == "" || strings.HasPrefix(strings.TrimSpace(line), "#") {
			continue
		}
		m := kvLine.FindStringSubmatch(line)
		if m == nil {
			return nil, "", fmt.Errorf("line %d: %q is not a flat \"key: value\" line", n, line)
		}
		fields[m[1]] = value(m[2])
	}
	return nil, "", errors.New("frontmatter is not closed by ---")
}

// value drops a trailing comment and surrounding quotes.
func value(v string) string {
	if i := strings.Index(v, " #"); i >= 0 {
		v = v[:i]
	}
	v = strings.TrimSpace(v)
	if len(v) >= 2 && (v[0] == '"' && v[len(v)-1] == '"' || v[0] == '\'' && v[len(v)-1] == '\'') {
		v = v[1 : len(v)-1]
	}
	return v
}

func (p *Probe) set(k, v string) error {
	var err error
	switch k {
	case "every":
		p.Every, err = ParseDuration(v)
	case "jitter":
		p.Jitter, err = ParseDuration(v)
	case "window":
		p.Window, err = ParseDuration(v)
	case "timeout":
		p.Timeout, err = ParseDuration(v)
	case "once":
		p.Once, err = strconv.ParseBool(v)
	case "floor":
		p.Floor = v
	case "expect":
		p.Expect, err = ParseExpect(v)
	case "confirm":

	case "channel":

	}

		return fmt.Errorf("%s: %s: %w", k, v, err)
	}
	return nil
}

func (p *Probe) check() error {
	switch {
	case p.Every == 0 && !p.Once:
		return errors.New("neither every nor once is set")
	case !slices.Contains(Wakes, p.Wake):
		return fmt.Errorf("wake: %s: accepted values are %s", p.Wake, strings.Join(Wakes, ", "))
	case !slices.Contains(Notifies, p.Notify):
		return fmt.Errorf("notify: %s: accepted values are %s", p.Notify, strings.Join(Notifies, ", "))

		return fmt.Errorf("sample: %g: must be between 0 and 1", p.Sample)

}

var dayRe = regexp.MustCompile(`^(\d+)d(.*)$`)

// ParseDuration accepts Go duration syntax plus a leading Nd (24 h) unit; the result must be
// positive (R-PRB-081).
func ParseDuration(s string) (time.Duration, error) {
	var days int
	if m := dayRe.FindStringSubmatch(s); m != nil {
		days, _ = strconv.Atoi(m[1])
		s = m[2]
	}
	var d time.Duration
	if s != "" {
		var err error
		if d, err = time.ParseDuration(s); err != nil {
			return 0, err
		}
	} else if days == 0 {
		return 0, errors.New("empty duration")
	}
	d += time.Duration(days) * 24 * time.Hour
	if d <= 0 {
		return 0, fmt.Errorf("%v is not a positive duration", d)
	}
	return d, nil
}

package probe

import (
	"fmt"
	"regexp"
	"strconv"
	"strings"
)

// Cond is one key op number condition of expect (R-PRB-025).
type Cond struct {
	Key, Op string
	Value   float64
}

var condRe = regexp.MustCompile(`^([A-Za-z_][A-Za-z0-9_]*)\s*(>=|<=|==|!=|>|<)\s*(-?\d+(?:\.\d+)?)$`)

// ParseExpect reads "key op number, key op number"; any other form is refused.
func ParseExpect(s string) ([]Cond, error) {
	var out []Cond
	for _, part := range strings.Split(s, ",") {
		m := condRe.FindStringSubmatch(strings.TrimSpace(part))
		if m == nil {
			return nil, fmt.Errorf("expect: %q is not \"key op number\" with op in >= <= > < == !=", strings.TrimSpace(part))
		}
		v, _ := strconv.ParseFloat(m[3], 64)
		out = append(out, Cond{Key: m[1], Op: m[2], Value: v})
	}
	return out, nil
}

// ParseKV reads the key=value pairs of a line; other words are ignored, a repeated key takes
// the last value, an empty key or value is dropped (R-PRB-024).
func ParseKV(line string) map[string]string {
	out := map[string]string{}
	for _, tok := range strings.Fields(line) {
		k, v, ok := strings.Cut(tok, "=")
		if ok && k != "" && v != "" {
			out[k] = v
		}
	}
	return out
}

// Satisfied reports whether every condition holds on kv; a missing key or a value that is not
// a number fails (R-PRB-023).
func Satisfied(conds []Cond, kv map[string]string) bool {
	for _, c := range conds {
		raw, ok := kv[c.Key]
		if !ok {
			return false
		}
		v, err := strconv.ParseFloat(raw, 64)
		if err != nil || !holds(c.Op, v, c.Value) {
			return false
		}
	}
	return true
}

func holds(op string, v, want float64) bool {
	switch op {
	case ">=":
		return v >= want
	case "<=":
		return v <= want
	case ">":
		return v > want
	case "<":
		return v < want
	case "==":
		return v == want
	}
	return v != want
}

package probe

import (
	"strings"
	"unicode/utf8"

	"github.com/enea-scaccabarozzi/ness/internal/shell"
)

// Floor states (R-PRB-020..023).
const (
	Green   = "GREEN"
	Red     = "RED"
	Unclear = "UNCLEAR"
	Vacuous = "VACUOUS"
)

// EvidenceCap is how much of the floor's output is kept (R-PRB-039).
const EvidenceCap = 4096

// Run is one floor run: its state, the capped and redacted evidence, and how it ended.
type Run struct {
	State    string
	Evidence string
	Exit     int
	TimedOut bool
}

// Floor is where a floor runs: the owner's worktree, the owner id, and the environment
// variables whose values are redacted from the evidence ([probes] redact_env).
type Floor struct {
	Dir, Owner string
	Redact     []string
	Getenv     func(string) string
}

// RunFloor runs p's floor as sh -c in f.Dir with NESS_PROBE and NESS_SESSION (R-PRB-083),
// killed at p.Timeout (R-PRB-022). The error is only "could not start".
func RunFloor(run shell.Runner, p Probe, f Floor) (Run, error) {
	r, err := run(shell.Cmd{
		Command: p.Floor, Dir: f.Dir, Timeout: p.Timeout,
		Env: []string{"NESS_PROBE=" + p.Path, "NESS_SESSION=" + f.Owner},
	})
	if err != nil {
		return Run{}, err
	}
	return Run{State: State(r, p.Expect), Evidence: Evidence(r.Output, f), Exit: r.Exit, TimedOut: r.TimedOut}, nil
}

// State classifies a floor result: timeout or an exit other than 0 and 1 is UNCLEAR, 1 is RED,
// 0 is GREEN unless expect is set and the last line's pairs do not satisfy it (VACUOUS).
func State(r shell.Result, expect []Cond) string {
	switch {
	case r.TimedOut, r.Exit != 0 && r.Exit != 1:
		return Unclear
	case r.Exit == 1:
		return Red
	case len(expect) > 0 && !Satisfied(expect, ParseKV(lastLine(r.Output))):
		return Vacuous
	}
	return Green
}

func lastLine(out []byte) string {
	lines := strings.Split(strings.TrimRight(string(out), "\n"), "\n")
	return lines[len(lines)-1]
}

// Evidence redacts the output, then keeps its last EvidenceCap bytes at a rune boundary
// (R-PRB-039): a secret can never survive as a fragment at the cut.
func Evidence(output []byte, f Floor) string {
	secrets := make([]string, 0, len(f.Redact))
	for _, name := range f.Redact {
		if v := f.Getenv(name); v != "" {
			secrets = append(secrets, v)
		}
	}
	text := Redact(string(output), secrets)
	if len(text) > EvidenceCap {
		text = text[len(text)-EvidenceCap:]
		for !utf8.ValidString(text) {
			text = text[1:]
		}
	}
	return text
}

// Redact replaces every occurrence of each secret with [redacted].
func Redact(text string, secrets []string) string {
	for _, s := range secrets {
		text = strings.ReplaceAll(text, s, "[redacted]")
	}
	return text
}

// Probe states (R-PRB-071): paused is a probe without a live owner; stopped is final.
const (
	ProbeActive  = "active"
	ProbePaused  = "paused"
	ProbeStopped = "stopped"
)

// ErrNoProbe is returned for a probe the store does not know.
var ErrNoProbe = errors.New("no such probe")

// Probe is one row: identity is Path plus Owner (R-PRB-084). NeedsEdit holds the file hash at
// a --probe-bug verdict, "" when none (R-PRB-065); FileError is the last reload failure.
type Probe struct {
	ID, Path, Owner, State          string
	LastState, Evidence, Hash       string
	Verdict, VerdictNote, NeedsEdit string
	Note, FileError                 string
	Streak, Runs                    int
	FinalWake                       bool
	StartedAt, NextRunAt, LastRunAt time.Time
	VerdictAt, StoppedAt            time.Time
}

// ProbeRun is what one scheduled run writes back.
type ProbeRun struct {
	State, Evidence, Hash, FileError string
	Streak, Runs                     int
	At, Next                         time.Time
}

// NewProbeID returns "p-" plus 8 base32 characters.
func NewProbeID() string {
	var b [5]byte
	if _, err := rand.Read(b[:]); err != nil {
		panic(err) // crypto/rand cannot fail on supported platforms
	}
	return "p-" + strings.ToLower(base32.StdEncoding.EncodeToString(b[:]))
}

const selectProbe = `SELECT id, path, owner, state, started_at, next_run_at, last_run_at, last_state, streak, runs,
	evidence, hash, file_error, verdict, verdict_note, verdict_at, needs_edit, final_wake, note, stopped_at FROM probes`

// StartProbe registers path for owner with its first run at next: the owner's own active
// probe restarts (its window too, unless keepWindow, R-PRB-062); a paused probe at the path
// is adopted (R-PRB-071); otherwise a new probe (R-PRB-060, R-PRB-084).
func (s *Store) StartProbe(path, owner string, keepWindow bool, next, now time.Time) (Probe, error) {
	var id string
	err := s.inTx(func(tx *sql.Tx) error {
		row := tx.QueryRowContext(context.Background(),
			`SELECT id FROM probes WHERE path = ? AND ((owner = ? AND state = 'active') OR state = 'paused')
			 ORDER BY CASE WHEN owner = ? THEN 0 ELSE 1 END LIMIT 1`, path, owner, owner)
		qerr := row.Scan(&id)
		switch {
		case errors.Is(qerr, sql.ErrNoRows):
			id = NewProbeID()
			_, qerr = tx.ExecContext(context.Background(),
				`INSERT INTO probes (id, path, owner, state, started_at, next_run_at) VALUES (?, ?, ?, 'active', ?, ?)`,
				id, path, owner, stamp(now), stamp(next))
			return qerr
		case qerr != nil:
			return qerr
		}
		started := `started_at`
		if !keepWindow {
			started = `?`
		}
		args := []any{owner, stamp(next)}
		if !keepWindow {
			args = append(args, stamp(now))
		}
		_, qerr = tx.ExecContext(context.Background(),
			`UPDATE probes SET owner = ?, state = 'active', next_run_at = ?, started_at = `+started+
				`, final_wake = 0, note = '', stopped_at = NULL WHERE id = ?`, append(args, id)...)
		return qerr
	})
	if err != nil {
		return Probe{}, err
	}
	return s.Probe(id)
}

// Probes lists active and paused probes by path then owner; all adds stopped ones.
func (s *Store) Probes(all bool) ([]Probe, error) {
	q := selectProbe + ` WHERE state <> 'stopped' ORDER BY path, owner`
	if all {
		q = selectProbe + ` ORDER BY path, owner`
	}
	return s.queryProbes(q)
}

// Probe returns one probe or ErrNoProbe.
func (s *Store) Probe(id string) (Probe, error) {
	return s.oneProbe(selectProbe+` WHERE id = ?`, id)
}

// ProbeOf returns the caller's active or paused probe at path (R-PRB-084), or ErrNoProbe.
func (s *Store) ProbeOf(path, owner string) (Probe, error) {
	return s.oneProbe(selectProbe+` WHERE path = ? AND owner = ? AND state <> 'stopped'`, path, owner)
}

func (s *Store) oneProbe(query string, args ...any) (Probe, error) {
	out, err := s.queryProbes(query, args...)
	if err != nil {
		return Probe{}, err
	}
	if len(out) == 0 {
		return Probe{}, ErrNoProbe
	}
	return out[0], nil
}

func (s *Store) queryProbes(query string, args ...any) (out []Probe, err error) {
	rows, err := s.db.QueryContext(context.Background(), query, args...)
	if err != nil {
		return nil, err
	}
	defer func() { err = errors.Join(err, rows.Close()) }()
	for rows.Next() {
		var (
			p                                          Probe
			started, next, last, verdictAt, stoppedAt  sql.NullString
		)
		if serr := rows.Scan(&p.ID, &p.Path, &p.Owner, &p.State, &started, &next, &last, &p.LastState, &p.Streak, &p.Runs,
			&p.Evidence, &p.Hash, &p.FileError, &p.Verdict, &p.VerdictNote, &verdictAt, &p.NeedsEdit, &p.FinalWake,
			&p.Note, &stoppedAt); serr != nil {
			return nil, serr
		}
		p.StartedAt, p.NextRunAt, p.LastRunAt = nullStamp(started), nullStamp(next), nullStamp(last)
		p.VerdictAt, p.StoppedAt = nullStamp(verdictAt), nullStamp(stoppedAt)
		out = append(out, p)
	}
	return out, rows.Err()
}

// RecordRun writes a run's outcome and the next run; a changed file clears needs-edit
// (R-PRB-065); a file error keeps the last state and evidence.
func (s *Store) RecordRun(id string, r ProbeRun) error {
	if r.FileError != "" {
		return s.touch(ErrNoProbe, `UPDATE probes SET file_error = ?, last_run_at = ?, next_run_at = ? WHERE id = ?`,
			r.FileError, stamp(r.At), stamp(r.Next), id)
	}
	return s.touch(ErrNoProbe,
		`UPDATE probes SET last_state = ?, evidence = ?, streak = ?, runs = ?, last_run_at = ?, next_run_at = ?,
		 needs_edit = CASE WHEN hash <> ? THEN '' ELSE needs_edit END, hash = ?, file_error = '' WHERE id = ?`,
		r.State, r.Evidence, r.Streak, r.Runs, stamp(r.At), stamp(r.Next), r.Hash, r.Hash, id)
}

// SetProbeState pauses, stops or reactivates a probe with a note.
func (s *Store) SetProbeState(id, state, note string, now time.Time) error {
	stopped := any(nil)
	if state == ProbeStopped {
		stopped = stamp(now)
	}
	return s.touch(ErrNoProbe, `UPDATE probes SET state = ?, note = ?, stopped_at = ? WHERE id = ?`, state, note, stopped, id)
}

// MarkFinalWake records that the window's final wake went out (R-PRB-042).
func (s *Store) MarkFinalWake(id string) error {
	return s.touch(ErrNoProbe, `UPDATE probes SET final_wake = 1 WHERE id = ?`, id)
}

// TransferProbes moves from's live probes to to (R-PRB-070); to the operator they pause with
// their last owner kept (R-PRB-071). One colliding with to's own probe at the path stops.
func (s *Store) TransferProbes(from, to string, now time.Time) (n int, err error) {
	err = s.inTx(func(tx *sql.Tx) error {
		ctx := context.Background()
		if to == Operator {
			res, xerr := tx.ExecContext(ctx, `UPDATE probes SET state = 'paused', note = 'owner closed'
				WHERE owner = ? AND state <> 'stopped'`, from)
			if xerr != nil {
				return xerr
			}
			c, _ := res.RowsAffected()
			n = int(c)
			return nil
		}
		res, xerr := tx.ExecContext(ctx, `UPDATE probes SET state = 'stopped', stopped_at = ?,
			note = 'merged into ' || (SELECT id FROM probes t WHERE t.path = probes.path AND t.owner = ? AND t.state <> 'stopped')
			WHERE owner = ? AND state <> 'stopped'
			AND EXISTS (SELECT 1 FROM probes t WHERE t.path = probes.path AND t.owner = ? AND t.state <> 'stopped')`,
			stamp(now), to, from, to)
		if xerr != nil {
			return xerr
		}
		merged, _ := res.RowsAffected()
		res, xerr = tx.ExecContext(ctx, `UPDATE probes SET owner = ?, note = 'from ' || owner
			WHERE owner = ? AND state <> 'stopped'`, to, from)
		if xerr != nil {
			return xerr
		}
		moved, _ := res.RowsAffected()
		n = int(merged + moved)
		return nil
	})
	return n, err
}

// SendWake puts a request from the owner to itself in its inbox, tagged with the probe

func (s *Store) SendWake(probeID, owner, body string, now time.Time) (string, error) {

		id, itemKey(owner, owner, IntentRequest, body, probeID, stamp(now)), nullable(owner), nullable(owner), body, stamp(now), probeID)

}

// Dispose answers an item with no reply item: a verdict answers a probe, not a session
// (R-PRB-064). A final disposition is ErrDisposed.
func (s *Store) Dispose(id, disposition, answer string, now time.Time) error {
	return s.inTx(func(tx *sql.Tx) error {
		var disp sql.NullString
		err := tx.QueryRowContext(context.Background(), `SELECT disposition FROM items WHERE id = ?`, id).Scan(&disp)
		if errors.Is(err, sql.ErrNoRows) {
			return ErrNoItem
		}
		if err != nil {
			return err
		}
		if disp.Valid && disp.String != Deferred {
			return ErrDisposed
		}
		_, err = tx.ExecContext(context.Background(),
			`UPDATE items SET disposition = ?, answer = ?, disposed_at = ? WHERE id = ?`, disposition, answer, stamp(now), id)
		return err
	})
}

// ReloadEvery is how soon a probe whose file does not parse is read again.
const ReloadEvery = time.Minute

// Probes is the scheduler slot's dependencies (R-WRK-060): where probe files and floors live,
// what to redact, the runner, the random source for jitter and sample, and the poster (nil:
// the notify feature is off).
type Probes struct {
	Primary string
	Redact  []string
	Getenv  func(string) string
	Run     shell.Runner
	Rand    *rand.Rand
	Post    func(channel, markdown, thread string) error
}

// probes runs every due probe. A probe whose owner is not an open session pauses, logged once
// (R-WRK-061); nothing here starts an agent (D10).
func (w *Worker) probes(now time.Time, live map[string]store.Session) {
	list, err := w.Store.Probes(false)
	if err != nil {
		w.Log.Error("probes", err)
		return
	}
	w.Log.Clear("probes")
	for _, p := range list {
		owner, ok := live[p.Owner]
		switch {
		case p.State == store.ProbePaused:
			continue
		case !ok:
			if perr := w.Store.SetProbeState(p.ID, store.ProbePaused, "owner "+p.Owner+" is not live", now); perr != nil {
				w.Log.Error(p.ID, perr)
				continue
			}
			w.Log.Action("pause", p.ID, "owner "+p.Owner+" is not live")
		case !p.NextRunAt.After(now):
			w.runProbe(p, owner, now)
		}
	}
}

// runProbe reloads the file (R-PRB-061), ends the window (R-PRB-042), runs the floor, decides
// the wake and the post, and schedules the next run.
func (w *Worker) runProbe(p store.Probe, owner store.Session, now time.Time) {
	root := filepath.Join(w.Probes.Primary, owner.Worktree)
	data, err := os.ReadFile(filepath.Join(root, filepath.FromSlash(p.Path))) //nolint:gosec // the owner's own file
	var pf probe.Probe
	if err == nil {
		pf, err = probe.Parse(p.Path, data)
	}
	if err != nil {
		w.Log.Error(p.ID+" file", err)
		w.record(p.ID, store.ProbeRun{FileError: err.Error(), At: now, Next: now.Add(ReloadEvery)})
		return
	}
	w.Log.Clear(p.ID + " file")
	if pf.Window > 0 && !now.Before(p.StartedAt.Add(pf.Window)) {
		w.endWindow(p, pf, now)
		return
	}
	run := probe.Run{}
	if !pf.Floorless() {
		f := probe.Floor{Dir: root, Owner: p.Owner, Redact: w.Probes.Redact, Getenv: w.Probes.Getenv}
		if run, err = probe.RunFloor(w.Probes.Run, pf, f); err != nil {
			w.Log.Error(p.ID+" floor", err)
			w.record(p.ID, store.ProbeRun{State: p.LastState, Evidence: p.Evidence, Hash: pf.Hash, Streak: p.Streak,
				Runs: p.Runs, At: now, Next: w.next(pf, now)})
			return
		}
		w.Log.Clear(p.ID + " floor")
	}
	streak := 0
	if !pf.Floorless() && run.State != probe.Green {
		streak = p.Streak + 1
	}
	rec := store.ProbeRun{State: run.State, Evidence: run.Evidence, Hash: pf.Hash, Streak: streak, Runs: p.Runs + 1,
		At: now, Next: w.next(pf, now)}
	w.record(p.ID, rec)
	w.Log.Action("probe", p.ID, fmt.Sprintf("%s (run %d, next %s)", stateOrDash(run.State), rec.Runs,
		rec.Next.UTC().Format(time.RFC3339)))
	confirmed := pf.Floorless() || run.State == probe.Green || streak >= pf.Confirm
	if w.wakes(pf, p.LastState, run.State, confirmed) {
		w.wake(p, pf, rec.Runs, run, false, now)
	}
	if !pf.Floorless() && pf.Notify == "auto" && run.State != p.LastState && confirmed {
		w.post(p, pf, fmt.Sprintf("probe %s: %s → %s\n\n```\n%s```\n", p.Path, stateOrDash(p.LastState), run.State, run.Evidence))
	}
	if pf.Once {
		w.stop(p.ID, "once: ran", now)
	}
}

func stateOrDash(s string) string {
	if s == "" {
		return "-"
	}
	return s
}

// wakes decides a wake (R-PRB-030..037): a floorless run always; otherwise the wake policy,
// gated by confirm for a non-GREEN state, plus the sampled GREENs.
func (w *Worker) wakes(pf probe.Probe, prev, state string, confirmed bool) bool {
	if pf.Floorless() {
		return true
	}
	if state == probe.Green && pf.Sample > 0 && w.Probes.Rand.Float64() < pf.Sample {
		return true
	}
	if state != probe.Green && !confirmed {
		return false
	}
	switch pf.Wake {
	case "always":
		return true
	case "change":
		return prev != "" && state != prev
	case "red":
		return state == probe.Red
	case "not-green":
		return state != probe.Green
	}
	return false
}

// next is the next run: every plus a random delay within jitter (R-PRB-040); once has no next.
func (w *Worker) next(pf probe.Probe, now time.Time) time.Time {
	if pf.Once {
		return time.Time{}
	}
	d := pf.Every
	if pf.Jitter > 0 {
		d += time.Duration(w.Probes.Rand.Int64N(int64(pf.Jitter)))
	}
	return now.Add(d)
}

// wake puts the request in the owner's inbox (R-PRB-038).
func (w *Worker) wake(p store.Probe, pf probe.Probe, run int, r probe.Run, final bool, now time.Time) {
	id, err := w.Store.SendWake(p.ID, p.Owner, WakeBody(pf, run, r, final), now)
	if err != nil {
		w.Log.Error(p.ID+" wake", err)
		return
	}
	w.Log.Clear(p.ID + " wake")
	w.Log.Action("wake", p.ID, id)
}

func (w *Worker) record(id string, r store.ProbeRun) {
	if err := w.Store.RecordRun(id, r); err != nil {
		w.Log.Error(id, err)
		return
	}
	w.Log.Clear(id)
}

func (w *Worker) stop(id, reason string, now time.Time) {
	if err := w.Store.SetProbeState(id, store.ProbeStopped, reason, now); err != nil {
		w.Log.Error(id, err)
		return
	}
	w.Log.Action("stop", id, reason)
}

// WakeBody is the wake item's text: the probe and run, the scope, the evidence, the answer.
func WakeBody(pf probe.Probe, run int, r probe.Run, final bool) string {
	var b strings.Builder
	switch {
	case final:
		fmt.Fprintf(&b, "probe %s: window elapsed, final verdict requested\n", pf.Path)
	case pf.Floorless():
		fmt.Fprintf(&b, "probe %s run %d\n", pf.Path, run)
	default:
		fmt.Fprintf(&b, "probe %s run %d: %s\n", pf.Path, run, r.State)
	}
	b.WriteString("\n" + pf.Scope + "\n")
	if r.Evidence != "" {
		b.WriteString("\nEvidence:\n```\n" + r.Evidence)
		if !strings.HasSuffix(r.Evidence, "\n") {
			b.WriteByte('\n')
		}
		b.WriteString("```\n")
	}
	b.WriteString("\nAnswer with: ness probe verdict ITEM --state green|red --note TEXT [--probe-bug]\n")
	return b.String()
}

// endWindow ends a probe whose window elapsed: one final wake asking for a verdict, then the
// stop (R-PRB-042). A probe already asked is left alone.
func (w *Worker) endWindow(p store.Probe, pf probe.Probe, now time.Time) {
	if !p.FinalWake {
		w.wake(p, pf, p.Runs, probe.Run{Evidence: p.Evidence}, true, now)
		if err := w.Store.MarkFinalWake(p.ID); err != nil {
			w.Log.Error(p.ID, err)
			return
		}
	}
	w.stop(p.ID, "window elapsed", now)
}

// post sends markdown to the probe's channel in the probe's own thread; with notify off, one
// log line per probe says so and the probe keeps running (R-PRB-051).
func (w *Worker) post(p store.Probe, pf probe.Probe, markdown string) {
	if w.Probes.Post == nil {
		w.Log.Error(p.ID+" post", errors.New("notify is off; probe posts are skipped"))
		return
	}
	if err := w.Probes.Post(pf.Channel, markdown, "probe:"+p.Path); err != nil {
		w.Log.Error(p.ID+" post", err)
		return
	}
	w.Log.Clear(p.ID + " post")
	w.Log.Action("post", p.ID, pf.Channel)
}

func VerdictNote(pf Probe, state, note string) string {
	return fmt.Sprintf("probe %s verdict: %s\n\n%s\n", pf.Path, strings.ToUpper(state), note)
}

// FirstRun is when a started probe first runs: now for every, within jitter for once
// (R-PRB-041), never past the window's end (R-PRB-042).
func FirstRun(pf Probe, now time.Time, r *rand.Rand) time.Time {
	first := now
	if pf.Once && pf.Jitter > 0 {
		first = now.Add(time.Duration(r.Int64N(int64(pf.Jitter))))
	}
	if pf.Window > 0 && first.After(now.Add(pf.Window)) {
		first = now.Add(pf.Window)
	}
	return first
}

// probeFiles turns the arguments into sorted repo-relative paths: a directory means its *.md
// files; a missing path or one outside the checkout refuses before anything is registered.
func probeFiles(root string, args []string) ([]string, error) {
	var out []string
	for _, a := range args {
		abs, err := filepath.Abs(a)
		if err != nil {
			return nil, err
		}
		info, err := os.Stat(abs)
		if err != nil {
			return nil, refuse("%s: %v", a, err)
		}
		files := []string{abs}
		if info.IsDir() {
			if files, err = filepath.Glob(filepath.Join(abs, "*.md")); err != nil {
				return nil, err
			}
		}
		for _, f := range files {
			rel, rerr := filepath.Rel(root, f)
			if rerr != nil || strings.HasPrefix(rel, "..") {
				return nil, refuse("%s is outside this checkout", f)
			}
			out = append(out, filepath.ToSlash(rel))
		}
	}
	slices.Sort(out)
	return out, nil
}

// parseProbes reads and validates every file; a notify policy needs the notify feature and a
// configured channel (D15: fail loudly at start, not at the first post).
func parseProbes(root string, cfg *config.Config, rels []string) ([]probe.Probe, error) {
	out := make([]probe.Probe, 0, len(rels))
	for _, rel := range rels {
		data, err := os.ReadFile(filepath.Join(root, filepath.FromSlash(rel))) //nolint:gosec // under the checkout
		if err != nil {
			return nil, refuse("%v", err)
		}
		pf, err := probe.Parse(rel, data)
		if err != nil {
			return nil, refuse("%v", err)
		}
		if pf.Notify != "none" {
			if !cfg.On("notify") {
				return nil, refuse("%s: notify: %s needs the notify feature; feature notify is off: add %q to features in %s",
					rel, pf.Notify, "notify", config.Path)
			}
			if _, ok := cfg.Notify.Channels[pf.Channel]; !ok {
				return nil, refuse("%s: channel %s is not in [notify.channels]", rel, pf.Channel)
			}
		}
		out = append(out, pf)
	}
	return out, nil
}

func runProbeStart(d Deps, args []string, keep bool) error {
	p, cfg, err := requireFeature(d, "probes")

// runProbeRun is the authoring loop (R-PRB-063): no store, no wake, no post.
func runProbeRun(d Deps, arg string, asJSON bool) error {
	p, cfg, err := requireFeature(d, "probes")
	if err != nil {
		return err
	}
	rels, err := probeFiles(p.root, []string{arg})
	if err != nil {
		return err
	}
	pfs, err := parseProbes(p.root, cfg, rels)
	if err != nil {
		return err
	}
	pf := pfs[0]
	if pf.Floorless() {
		say(d.Stdout, "no floor\n%s", pf.Scope)
		return nil
	}
	f := probe.Floor{Dir: p.root, Owner: displayName(d.Session), Redact: cfg.Probes.RedactEnv, Getenv: os.Getenv}
	run, err := probe.RunFloor(d.shell(), pf, f)
	if err != nil {
		return err
	}
	if asJSON {
		enc := json.NewEncoder(d.Stdout)
		enc.SetIndent("", "  ")
		if err = enc.Encode(map[string]any{"schema": 1, "state": run.State, "exit": run.Exit,
			"timed_out": run.TimedOut, "evidence": run.Evidence}); err != nil {
			return err
		}
	} else {
		state := run.State
		if run.TimedOut {
			state += " (timeout)"
		}
		say(d.Stdout, "%s\n%s", state, strings.TrimRight(run.Evidence, "\n"))
	}
	if run.State != probe.Green {
		return exitCode(ExitProblems)
	}
	return nil
}
