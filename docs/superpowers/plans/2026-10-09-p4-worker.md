# P4 Worker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ness worker run` is the one process per project that wakes idle sessions with a typed hint for every unread item, compacts a session at its recorded boundary, stays silent on a usage-limited pane and resumes it after the reset, reports stalls and screen errors to the manager, stops a session whose model went away, retires zombie items, writes a heartbeat every pass and one log line per action, and restarts itself when its binary changes; `ness worker install` puts it under a systemd user unit that `ness doctor` already checks.

**Architecture:** `internal/worker` is the pass (`Worker.Pass`: heartbeat, retirement, one visit per ready session over the `session.Runtime` seam and the `store`), the loop (`Loop.Run`: a 5 s ticker and a 60 s binary check), the lock, the hint text and the rotated `worker.log`. The client atom `internal/atom/claude` learns to read a pane: the input box as ANSI (dim text is the placeholder), the usage-limit notices with their reset time, the error patterns, the model-unavailable notice, the resume text, and the usage file. The runtime seam gains `ReadANSI` and the agent name and focus in `PaneState`; the herdr atom and the fake implement them. `internal/atom/systemd` renders and installs the unit; `internal/cli/worker.go` composes `run`, `install`, `uninstall`. The store gains `Unread`, `RetireDead`, `ClearBoundary` and the reply-to-reply refusal; no migration is needed (the heartbeat table and `retired_at` landed in migration 2).

**Tech Stack:** Go 1.27 (mise), `modernc.org/sqlite`, cobra, testscript, `testing/synctest` for the loop, `syscall.Flock` for the lock, `systemctl --user` through the `Exec` seam. The P1–P3 gate (`make validate`) stays as is.

**Spec:** `docs/superpowers/specs/2026-10-08-ness-v1-scope.md` (P4 row), `docs/design/ness-design.md` §2 (seams: runtime, client, supervisor), §4 (herdr, systemd, model unavailable), §5 "Machinery", §6 (`worker.log`, the unit), §13 (kill polling), §14 (worker rules), §16 #3, and the requirements in `docs/spec/worker.md` (WRK, all 44), plus the carry-ins `docs/spec/sessions.md` R-SESS-009, `docs/spec/models.md` R-MOD-012 (worker half), `docs/spec/store-messages.md` R-MSG-005 and R-MSG-042, `docs/spec/core-config.md` `[worker]` keys (R-CFG-042).

## Global Constraints

- Everything of P3a/P3b's Global Constraints holds; every external program (herdr, systemctl, the re-executed binary) runs through `Deps.Exec` (`cli.SystemExec` in production, `testkit.FakeExec` in tests); git discovery variables stripped.
- Exit codes: 0 ok, 1 problems, 2 usage, 3 conflict, 4 refused (R-CFG-035). A second `worker run`, a missing or old herdr, and `install` without a systemd user session are refusals (exit 4).
- The worker pass interval is exactly 5 s (R-WRK-024); the binary is re-resolved every 60 s (R-WRK-009); `worker.stall_minutes` defaults to 30 and `worker.quiet_seconds` to 60 (R-CFG-042, already in `config.Worker`).
- The worker types only with `Runtime.Run` (text and Enter) and only into a pane whose agent is live, `idle` (never `working`, `blocked`, `done` or `unknown`), is the session's own agent (the stored name; P3a's foreign-agent rule), is not the operator's focused pane, whose input box is empty (dim text is empty), and whose session is not usage-limited. Nothing else is ever typed: no `/model`, no effort command (R-MOD-012).
- The worker's only files are `<git-common-dir>/ness/worker.log` (`.1`, `.2` after rotation at 10 MB), `<git-common-dir>/ness/worker.lock` and the store. `ness worker install` writes exactly `~/.config/systemd/user/ness-<project>.service` and nothing else outside the repository (R-WRK-002); the unit's `ExecStart=` is the absolute real path of the running binary followed by `worker run` (R-WRK-003), which is what `checkWorkerBinary` in `internal/cli/doctor_checks.go` parses.
- The heartbeat row (`store.SetHeartbeat`) is written on every pass with the binary's version (R-WRK-008); `ness status` and `ness doctor` read it unchanged.
- No wall-clock sleep anywhere in tests (`.golangci.tests.yml` forbids `time.Sleep`): pass-level tests step an injected clock; loop-level tests run under `testing/synctest`.
- Real-client runs stay behind the `e2e` tag and `testkit.RequireBudget` (80% weekly usage, D31); this plan adds no e2e test and all its tests run on the fakes.
- Migrations are append-only and stay at version 3: this plan adds no migration.
- Every test names the requirement ids it covers (`// covers: R-…`, `# covers: R-…`). Conventional commits with the session's trailers. No push and no CI watch in this plan: the controller merges.

## Review Focus

1. **A hint whose `Run` fails (herdr answered an error, the pane vanished between the state read and the typing).** The hinted set must not be updated, so the next pass retries, and the error is logged once. Pinned in Task 5 (`TestRunFailureRetriesNextPass`).
2. **A pane whose agent is not the session's own** (the operator started another client in it, or herdr reused the pane). Nothing is typed, one log line names both agents, later passes stay silent. Pinned in Task 5 (`TestForeignAgentIsNeverTyped`).
3. **A limit notice whose parsed reset is absurdly far away** ("resets Oct 1" read on Oct 2 resolves to next year, R-WRK-044). The pane must not fall silent for a year: a reset more than 8 days ahead is handled as an unknown reset (silent, re-read every 15 min). Pinned in Task 6 (`TestFarResetIsHandledAsUnknown`).
4. **`worker.log` unwritable** (a read-only common dir, a full disk). The pass must still run, the heartbeat still land, the failure reported once on stderr. Pinned in Task 4 (`TestLogFailureNeverStopsTheCaller`).
5. **A pass that fails mid-way** (the store busy past `busy_timeout`, a runtime error at the first session). The loop logs it once and keeps its 5 s cadence; it never exits. Pinned in Task 8 (`TestLoopSurvivesFailingPasses`).

## Rulings

- **Replies wake, and a reply cannot be replied to.** The worker hints every unread listed item, replies included (the asker ended its turn waiting for exactly that). `store.Reply` on a `reply` item returns `ErrReplyToReply` and `ness reply` refuses (exit 4): a reply is read with `inbox --show`, and a conversation continues with a new `send`. Without this, two sessions could bounce replies forever, each waking the other.
- **Reports to the manager are `fyi` items sent by the session they are about.** A stall, a screen error and a stop are `Send(sess.ID, sess.Parent, fyi, body)`: the route is legal (child → manager, root → operator), the manager can read and reply, and the body carries the episode's start time so the idempotency key (R-MSG-014) makes one item per episode and no second item for the same one. A stop is urgent.
- **Model unavailable = the tab is closed, the row stays open, the manager is told the fix** (`[tiers.<tier>]`, then `ness open --resume ID`). The worker never changes a model or effort (R-MOD-012); the manager resumes one tier up.
- **The quiet window's "operator input" is a proxy:** the pane was the operator's focused pane, or its box held a draft, at any pass in the last `quiet_seconds`. herdr reports neither keystrokes nor input time (`AgentInfo` has `focused`, `revision`, `state_change_seq`; `revision` moves on the agent's own output too), and the session's transcript writes and tool calls never touch either signal (R-WRK-018, F3).
- **Limit notices are read from the visible screen** (`pane read --source visible --format ansi`, the new `ReadANSI`). A notice with a reset time silences the pane until reset + 60 s, then one `continue` is typed (the client's resume text, `claude.ResumeText`); after that the still-visible notice is stale (its reset passed) and delivery resumes. A notice without a reset time silences the pane while it is visible and the screen is re-read every 15 min. The launcher's `ReadScreen` (recent, text) is unchanged.
- **Codex sessions are not delivered to in v1.** The worker holds a `Client` (reader and resume text) per client name; a session of a client without one is skipped with one log line. Codex is experimental (0 clean launches) and has no screen reader yet.
- **An adopted root** (`--here`, no agent name bound) is delivered to when herdr shows a live idle agent in its pane, whatever its name; otherwise it is skipped with one log line.
- **The restart check re-executes the running binary's real path** (`realPath(os.Executable())`, the same path the unit's `ExecStart=` carries) with `--version` every 60 s; a different version means exit 0 and systemd restarts (`Restart=always`). A binary installed under a new versioned directory (mise) needs `ness worker install` again, which `doctor`'s `worker-binary` check says.
- **The discovery screens stay private (D30).** The R-WRK-015 table and the R-WRK-070 corpus are built from the client's rendering (prompt `> `, placeholder in SGR 2 or 90) and the notice strings quoted in the spec; no file under `docs/discovery` is copied into `testdata`.
- **`ness worker run --once`** runs one pass and exits: the script seam, and a way for an operator to run a pass by hand.
- **`worker.log` dedup is per key:** an identical error for the same session (or `pass`, `binary`) is written once until that key succeeds again, so the log shows error → recovery → error, never a storm.

package session

import (
	"regexp"
	"time"
)

// Screen is what a client's pane shows that the worker acts on, as its client atom reads it:
// the operator's draft in the input box ("" when empty or when the box shows the client's dim
// placeholder, R-WRK-015), a live usage-limit notice (R-WRK-040), the first matched error
// pattern (R-WRK-051) and whether the tier's model is reported unavailable (R-SESS-009).
type Screen struct {
	Draft       string
	Limit       *Limit
	Error       string
	Unavailable bool
}

// Limit is a usage-limit notice: its text and the reset time it names, zero when it names none
// (R-WRK-045).
type Limit struct {
	Notice string
	Reset  time.Time
}

// ansiRe matches CSI sequences, OSC strings (title, hyperlink) and two-byte escapes.
var ansiRe = regexp.MustCompile(`\x1b\[[0-?]*[ -/]*[@-~]|\x1b\][^\a]*(?:\a|\x1b\\)|\x1b[@-Z\\-_]`)

// StripANSI returns s without terminal escape sequences.
func StripANSI(s string) string { return ansiRe.ReplaceAllString(s, "") }
```

// ponytail: "capacity" also matches prose about capacity; a false stall report is one fyi to the

var ErrorPatterns = []*regexp.Regexp{

	regexp.MustCompile(`(?i)\boverloaded\b`),
	regexp.MustCompile(`(?i)\bcapacity\b`),

// ponytail: the not_found_error shape of the API and three prose forms; widen when a new one shows.
var unavailableRe = regexp.MustCompile(

// R-WRK-051, R-SESS-009). A limit notice wins over the error patterns: a limited pane is silent,
// not stalled.

		sc.Limit = &lim
		return sc

	for _, re := range ErrorPatterns {
		if m := re.FindString(text); m != "" {
			sc.Error = m
			break
		}
	}
	return sc
}

// escRe matches one escape sequence at the start of a string; the SGR parameters are captured.
var escRe = regexp.MustCompile(`^(?:\x1b\[([0-?]*)[ -/]*([@-~])|\x1b\][^\a]*(?:\a|\x1b\\)|\x1b[@-Z\\-_])`)

// InputBox returns the operator's draft: the text after the last "> " prompt of the visible
// screen without escape sequences, or "" when the box is empty or shows only dim text, which is
// the client's placeholder suggestion (R-WRK-015, the P3 placeholder regression). Box drawing and
// spaces before the prompt are skipped.
func InputBox(ansi string) string {
	lines := strings.Split(ansi, "\n")
	for i := len(lines) - 1; i >= 0; i-- {
		if rest, ok := promptRest(lines[i]); ok {
			return strings.TrimSpace(brightText(rest))
		}
	}
	return ""
}

// promptRest returns what follows the prompt marker when line is the input box: optional box
// characters and spaces, then ">" alone or followed by a space. The raw line is cut at its first
// ">" so the escapes after the prompt are kept for brightText.
func promptRest(line string) (string, bool) {
	plain := strings.TrimLeft(session.StripANSI(line), "│ \t")
	if plain != ">" && !strings.HasPrefix(plain, "> ") {
		return "", false
	}
	i := strings.Index(line, ">")
	if i < 0 {
		return "", false
	}
	return line[i+1:], true
}

// brightText returns the characters of s rendered at normal intensity: SGR 2 (faint) and SGR 90
// (bright black, the client's grey) mark dim text until SGR 22, 39 or 0.
func brightText(s string) string {
	var out strings.Builder
	dim, grey := false, false
	for s != "" {
		m := escRe.FindStringSubmatch(s)
		if m == nil {
			r, size := utf8DecodeRune(s)
			if !dim && !grey {
				out.WriteString(r)
			}
			s = s[size:]
			continue
		}
		if m[2] == "m" {
			for _, p := range strings.Split(m[1], ";") {
				switch p {
				case "", "0":
					dim, grey = false, false
				case "2":
					dim = true
				case "22":
					dim = false
				case "90":
					grey = true
				case "39":
					grey = false
				}
			}
		}
		s = s[len(m[0]):]
	}
	return out.String()
}

// utf8DecodeRune returns the first rune of s as a string and its byte length.
func utf8DecodeRune(s string) (string, int) {
	for i := range s {
		if i > 0 {
			return s[:i], i
		}
	}
	return s, len(s)
}

var (
	limitRe = regexp.MustCompile(`(?i)You'?ve (?:hit|reached) your ([\w ]+?) limit(?:\s*·\s*resets\s+([^\n]+))?`)
	resetRe = regexp.MustCompile(`(?i)^(?:(jan|feb|mar|apr|may|jun|jul|aug|sep|oct|nov|dec)\w*\s+(\d{1,2}),?\s*)?` +
		`(?:(\d{1,2})(?::(\d{2}))?\s*(am|pm))?`)
	months = map[string]time.Month{
		"jan": 1, "feb": 2, "mar": 3, "apr": 4, "may": 5, "jun": 6,
		"jul": 7, "aug": 8, "sep": 9, "oct": 10, "nov": 11, "dec": 12,
	}
)

// ParseLimit finds the first usage-limit notice in text (R-WRK-040, the F2 regression) and the
// reset it names, in now's location (R-WRK-046): a time without a date is today, or tomorrow when
// it is more than an hour past (a notice read right after its reset is that reset, not the next
// day's); a date without a year is this year, or next year when the day is past (R-WRK-044). A
// date without a time is that day at 00:00. A notice without a reset has a zero Reset.
func ParseLimit(text string, now time.Time) (session.Limit, bool) {
	m := limitRe.FindStringSubmatch(text)
	if m == nil {
		return session.Limit{}, false
	}
	lim := session.Limit{Notice: strings.TrimSpace(m[0])}
	reset := strings.TrimRight(strings.TrimSpace(m[2]), ". ")
	r := resetRe.FindStringSubmatch(reset)
	if r == nil || (r[1] == "" && r[3] == "") {
		return lim, true
	}
	hour, minute := 0, 0
	if r[3] != "" {
		hour, _ = strconv.Atoi(r[3])
		minute, _ = strconv.Atoi(r[4])
		if hour > 12 || minute > 59 {
			return lim, true
		}
		hour %= 12
		if strings.EqualFold(r[5], "pm") {
			hour += 12
		}
	}
	loc := now.Location()
	if r[1] == "" {
		t := time.Date(now.Year(), now.Month(), now.Day(), hour, minute, 0, 0, loc)
		if t.Before(now.Add(-time.Hour)) {
			t = t.AddDate(0, 0, 1)
		}
		lim.Reset = t
		return lim, true
	}
	day, _ := strconv.Atoi(r[2])
	t := time.Date(now.Year(), months[strings.ToLower(r[1])], day, hour, minute, 0, 0, loc)
	today := time.Date(now.Year(), now.Month(), now.Day(), 0, 0, 0, 0, loc)
	if t.Before(today) {
		t = t.AddDate(1, 0, 0)
	}
	lim.Reset = t
	return lim, true
}

// Usage reads the client's usage snapshot, ~/.claude/usage-latest.json (the statusline input it
// last wrote; testkit.UsageGuard reads the same file): the latest end of a window at 100% that
// has not reset, or false (R-WRK-047). A missing, unreadable or malformed file is no limit.
func Usage(home string, now time.Time) (time.Time, bool) {
	data, err := os.ReadFile(filepath.Join(home, ".claude", "usage-latest.json")) //nolint:gosec // the user's own snapshot
	if err != nil {
		return time.Time{}, false
	}
	var u struct {
		RateLimits map[string]struct {
			Used     float64 `json:"used_percentage"`
			ResetsAt float64 `json:"resets_at"`
		} `json:"rate_limits"`
	}
	if json.Unmarshal(data, &u) != nil {
		return time.Time{}, false
	}
	var until time.Time
	for _, w := range u.RateLimits {
		if r := time.Unix(int64(w.ResetsAt), 0); w.Used >= 100 && r.After(now) && r.After(until) {
			until = r
		}
	}
	return until, !until.IsZero()
}

// Package worker is the per-project worker (design §5 "Machinery", §14): the pass that wakes
// idle sessions, compacts them at their boundary, keeps limited panes silent and resumes them,
// reports stalls, stops a session whose model went away, retires zombie items and writes the
// heartbeat; the loop that runs it every 5 s and restarts on a binary change; the lock; the log.
package worker

import (
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"time"
)

const (
	// LogMax is the size at which worker.log rotates (R-WRK-026).
	LogMax = 10 << 20
	// LogKeep is how many rotated files stay: worker.log.1 and .2.
	LogKeep = 2
)

// Log is worker.log (R-WRK-021): one line per action, rotated at LogMax keeping LogKeep files
// (R-WRK-026), an identical error per key written once until the key clears (R-WRK-022). A
// write failure is reported once on Err and never stops the caller.
type Log struct {
	Path string
	Max  int64 // 0 means LogMax
	Now  func() time.Time
	Err  io.Writer // nil discards

	last   map[string]string
	failed bool
}

// Action writes one line: stamp, action, subject (a session or item id, "-" for the process), detail.
func (l *Log) Action(action, subject, detail string) {
	l.write(action + " " + subject + " " + detail)
}

// Error writes the error for key unless it is the one last written for key.
func (l *Log) Error(key string, err error) {
	text := err.Error()
	if l.last == nil {
		l.last = map[string]string{}
	}
	if l.last[key] == text {
		return
	}
	l.last[key] = text
	l.write("error " + key + " " + text)
}

// Clear forgets key's last error: the next identical one is written again.
func (l *Log) Clear(key string) { delete(l.last, key) }

func (l *Log) write(line string) {
	err := l.rotate()
	if err == nil {
		var f *os.File
		f, err = os.OpenFile(l.Path, os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0o600) //nolint:gosec // the project's own log
		if err == nil {
			_, err = fmt.Fprintf(f, "%s %s\n", l.Now().UTC().Format(time.RFC3339), line)
			err = errors.Join(err, f.Close())
		}
	}
	if err != nil && !l.failed && l.Err != nil {
		l.failed = true
		_, _ = fmt.Fprintf(l.Err, "ness: %s: %v (logging disabled for this run)\n", l.Path, err) //nolint:errcheck // nowhere left to report
	}
}

// rotate shifts worker.log to .1 and .1 to .2 when it reached Max; a missing log is nothing to rotate.
func (l *Log) rotate() error {
	max := l.Max
	if max == 0 {
		max = LogMax
	}
	fi, err := os.Stat(l.Path)
	if errors.Is(err, fs.ErrNotExist) {
		return os.MkdirAll(filepath.Dir(l.Path), 0o750)
	}
	if err != nil || fi.Size() < max {
		return err
	}
	for i := LogKeep; i > 1; i-- {
		if rerr := os.Rename(rotated(l.Path, i-1), rotated(l.Path, i)); rerr != nil && !errors.Is(rerr, fs.ErrNotExist) {
			return rerr
		}
	}
	return os.Rename(l.Path, rotated(l.Path, 1))
}

func rotated(path string, n int) string { return fmt.Sprintf("%s.%d", path, n) }

// Hint is the text typed to wake a session (R-WRK-025): the unread count, the intent mix sorted,
// the command to run; "now" when any item is urgent. Frozen by TestHintGolden.
func Hint(items []store.Item) string {
	var intents []string
	urgent := false
	for _, it := range items {
		if !slices.Contains(intents, it.Intent) {
			intents = append(intents, it.Intent)
		}
		urgent = urgent || it.Urgent
	}
	slices.Sort(intents)
	mix := strings.Join(intents, ", ")
	if urgent {
		return fmt.Sprintf("ness: %d unread, urgent (%s); run ness inbox now", len(items), mix)
	}
	return fmt.Sprintf("ness: %d unread (%s); run ness inbox", len(items), mix)
}

package worker

import (
	"errors"
	"fmt"
	"slices"
	"time"

	"github.com/enea-scaccabarozzi/ness/internal/session"
	"github.com/enea-scaccabarozzi/ness/internal/store"
)

// Interval is the pass interval (R-WRK-024).
const Interval = 5 * time.Second

// Client is what the worker needs from a client atom: how to read its pane (R-WRK-015,
// R-WRK-040, R-WRK-051) and the text that resumes it after a usage limit (R-WRK-043).
type Client struct {
	Read   func(ansi string, now time.Time) session.Screen
	Resume string
}

// Worker is one project's worker: the store, the runtime, a Client per client name (a session of
// a client without one is skipped), the client's usage file (nil: none), the binary's version for
// the heartbeat, the clock, the log, and the stall and quiet windows from [worker].
type Worker struct {
	Store   *store.Store
	Runtime session.Runtime
	Clients map[string]Client
	Usage   func(now time.Time) (time.Time, bool)
	Version string
	Now     func() time.Time
	Log     *Log
	Stall   time.Duration
	Quiet   time.Duration

	panes map[string]*pane // by session id; what the worker remembers between passes
}

// pane is what the worker remembers of a session's pane: the ids its last hint covered, when the
// operator last had it (focus or a draft), the live limit notice, the stall episode.
type pane struct {
	hinted               []string
	lastFocus, lastDraft time.Time
	limit                *session.Limit
	nextRead             time.Time
	resumed              bool
	idleSince            time.Time
	stalled, errored     bool
	stopped              bool
}

func (p *pane) working() {
	p.idleSince = time.Time{}
	p.stalled, p.errored = false, false
}

// quiet reports whether the operator used the pane within q (R-WRK-018): focus or a draft.
func (p *pane) quiet(now time.Time, q time.Duration) bool {
	last := p.lastFocus
	if p.lastDraft.After(last) {
		last = p.lastDraft
	}
	return !last.IsZero() && now.Sub(last) < q
}

// Pass is one pass (design §5 "Machinery"): the heartbeat (R-WRK-008), zombie retirement
// (R-WRK-020), then every open session's pane. The error is the store's; a pane's trouble is
// logged and the pass goes on to the next session.
func (w *Worker) Pass() error {
	now := w.Now()
	if err := w.Store.SetHeartbeat(now, w.Version); err != nil {
		return err
	}
	retired, err := w.Store.RetireDead(now)
	if err != nil {
		return err
	}
	for _, id := range retired {
		w.Log.Action("retire", id, "recipient closed or unknown")
	}
	sessions, err := w.Store.Sessions(false)
	if err != nil {
		return err
	}
	if w.panes == nil {
		w.panes = map[string]*pane{}
	}
	live := map[string]bool{}
	for _, sess := range sessions {
		live[sess.ID] = true
		w.visit(sess, now)
	}
	for id := range w.panes {
		if !live[id] {
			delete(w.panes, id)
		}
	}
	return nil
}

func (w *Worker) pane(id string) *pane {
	p, ok := w.panes[id]
	if !ok {
		p = &pane{}
		w.panes[id] = p
	}
	return p
}

// visit decides what one session's pane gets this pass. A session still launching (no pane, no
// ready mark) gets nothing; a pane whose agent is gone, not the session's own, or not idle gets
// nothing and one log line (R-WRK-013); the operator's focused pane and a non-empty box get
// nothing (R-WRK-014, R-WRK-017); otherwise one hint (R-WRK-010, R-WRK-011, R-WRK-019).
func (w *Worker) visit(sess store.Session, now time.Time) {
	c, ok := w.Clients[sess.Client]
	if !ok {
		w.Log.Error(sess.ID, fmt.Errorf("client %s is not delivered to", sess.Client))
		return
	}
	if sess.Pane == "" || sess.ReadyAt.IsZero() {
		return
	}
	p := w.pane(sess.ID)
	st, err := w.Runtime.State(sess.Pane)
	switch {
	case err != nil:
	case !st.Live:
		err = errors.New("no agent in pane " + sess.Pane)
	case sess.Agent != "" && st.Agent != sess.Agent:
		err = fmt.Errorf("pane %s runs agent %s, not %s", sess.Pane, st.Agent, sess.Agent)
	}
	if err != nil {
		w.Log.Error(sess.ID, err)
		return
	}
	w.Log.Clear(sess.ID)
	if st.Status != "idle" {
		p.working()
		return
	}
	if p.idleSince.IsZero() {
		p.idleSince = now
	}
	if st.Focused {
		p.lastFocus = now
	}
	screen, err := w.Runtime.ReadANSI(sess.Pane)
	if err != nil {
		w.Log.Error(sess.ID+" read", err)
		return
	}
	w.Log.Clear(sess.ID + " read")
	sc := c.Read(screen, now)
	if sc.Draft != "" {
		p.lastDraft = now
	}
	if st.Focused || sc.Draft != "" {
		return
	}
	w.hint(sess, p, now)
}

// hint types one hint covering every unread item when the set has an item the last hint did not
// cover (R-WRK-011, R-WRK-012); a non-urgent set waits out the quiet window, an urgent item
// does not (R-MSG-042). A failed Run leaves the set uncovered, so the next pass retries.
func (w *Worker) hint(sess store.Session, p *pane, now time.Time) {
	items, err := w.Store.Unread(sess.ID)
	if err != nil {
		w.Log.Error(sess.ID, err)
		return
	}
	if len(items) == 0 {
		p.hinted = nil
		return
	}
	fresh, urgent := false, false
	for _, it := range items {
		if !slices.Contains(p.hinted, it.ID) {
			fresh = true
			urgent = urgent || it.Urgent
		}
	}
	if !fresh || (!urgent && p.quiet(now, w.Quiet)) {
		return
	}
	if err := w.Runtime.Run(sess.Pane, Hint(items)); err != nil {
		w.Log.Error(sess.ID+" hint", err)
		return
	}
	w.Log.Clear(sess.ID + " hint")
	p.hinted = make([]string, 0, len(items))
	for _, it := range items {
		p.hinted = append(p.hinted, it.ID)
	}
	w.Log.Action("hint", sess.ID, fmt.Sprintf("%d unread", len(items)))
}
```
Log keys: pane and agent trouble is keyed by the session id and cleared when the pane answers again; a failed read, hint, compaction, resume or report is keyed `<id> read|hint|compact|resume|stall|stop|tell` and cleared by its own success, so each error kind is written once until it recovers (R-WRK-022). The `Usage` field is read from Task 6; `Clients` without a `Usage` is fine.

package worker

import (
	"time"

	"github.com/enea-scaccabarozzi/ness/internal/session"
	"github.com/enea-scaccabarozzi/ness/internal/store"
)

const (
	resumeGrace  = time.Minute        // typed at reset + 60 s (R-WRK-043)
	limitRecheck = 15 * time.Minute   // how often a pane under a reset-less notice is read (R-WRK-045)
	limitHorizon = 8 * 24 * time.Hour // a reset further away is not trusted (Review Focus 3)
)

// read returns the pane's visible screen. A pane under a notice without a reset time is read
// again only every limitRecheck (R-WRK-045); in between the pane is left alone.
func (w *Worker) read(sess store.Session, p *pane, now time.Time) (string, bool) {
	if p.limit != nil && p.limit.Reset.IsZero() && now.Before(p.nextRead) {
		return "", false
	}
	screen, err := w.Runtime.ReadANSI(sess.Pane)
	if err != nil {
		w.Log.Error(sess.ID+" read", err)
		return "", false
	}
	w.Log.Clear(sess.ID + " read")
	p.nextRead = now.Add(limitRecheck)
	return screen, true
}

// noteLimit records the notice on screen: a new notice, or a new reset, is logged once and arms
// one resume; a reset beyond limitHorizon is handled as unknown; no notice clears the state.
func (w *Worker) noteLimit(sess store.Session, p *pane, lim *session.Limit, now time.Time) {
	if lim == nil {
		p.limit, p.resumed = nil, false
		return
	}
	if !lim.Reset.IsZero() && lim.Reset.Sub(now) > limitHorizon {
		lim = &session.Limit{Notice: lim.Notice}
	}
	if p.limit == nil || !p.limit.Reset.Equal(lim.Reset) {
		p.resumed = false
		when := "no reset time"
		if !lim.Reset.IsZero() {
			when = "resets " + lim.Reset.UTC().Format(time.RFC3339)
		}
		w.Log.Action("limited", sess.ID, when)
	}
	p.limit = lim
}

// limited reports whether the pane stays silent now (R-WRK-042): a notice without a reset while
// it is on screen; a notice with one until reset + 60 s, after which it is stale.
func (p *pane) limited(now time.Time) bool {
	switch {
	case p.limit == nil:
		return false
	case p.limit.Reset.IsZero():
		return true
	}
	return now.Before(p.limit.Reset.Add(resumeGrace))
}

// resume types the client's resume text once after a known reset passed (R-WRK-043) and reports
// whether this pass was spent on it. The idle clock restarts: the limit was not the agent's idling.
func (w *Worker) resume(sess store.Session, p *pane, c Client, now time.Time) bool {
	if p.limit == nil || p.limit.Reset.IsZero() || p.resumed {
		return false
	}
	if err := w.Runtime.Run(sess.Pane, c.Resume); err != nil {
		w.Log.Error(sess.ID+" resume", err)
		return true
	}
	w.Log.Clear(sess.ID + " resume")
	p.resumed, p.idleSince = true, now
	w.Log.Action("resume", sess.ID, "after the reset at "+p.limit.Reset.UTC().Format(time.RFC3339))
	return true
}

// compact types /compact with the boundary note and clears the request (R-WRK-030, R-WRK-032).
// The note is one line: the command is one line.
func (w *Worker) compact(sess store.Session) {
	if err := w.Runtime.Run(sess.Pane, "/compact "+store.Excerpt(sess.BoundaryNote, 500)); err != nil {
		w.Log.Error(sess.ID+" compact", err)
		return
	}
	if err := w.Store.ClearBoundary(sess.ID); err != nil {
		w.Log.Error(sess.ID+" compact", err)
		return
	}
	w.Log.Clear(sess.ID + " compact")
	w.Log.Action("compact", sess.ID, sess.BoundaryNote)
}

// visit decides what one session's pane gets this pass. A session still launching (no pane, no
// ready mark) gets nothing; a pane whose agent is gone, not the session's own, or not idle gets
// nothing and one log line (R-WRK-013); a limited pane is silent (R-WRK-042, R-WRK-047) and
// resumed once after its reset (R-WRK-043); the operator's focused pane and a non-empty box get
// nothing (R-WRK-014, R-WRK-017); then a compaction at the boundary (R-WRK-030) or one hint
// (R-WRK-010, R-WRK-011, R-WRK-019).
func (w *Worker) visit(sess store.Session, now, fileLimit time.Time) {
	c, ok := w.Clients[sess.Client]
	if !ok {
		w.Log.Error(sess.ID, fmt.Errorf("client %s is not delivered to", sess.Client))
		return
	}
	if sess.Pane == "" || sess.ReadyAt.IsZero() {
		return
	}
	p := w.pane(sess.ID)
	st, err := w.Runtime.State(sess.Pane)
	switch {
	case err != nil:
	case !st.Live:
		err = errors.New("no agent in pane " + sess.Pane)
	case sess.Agent != "" && st.Agent != sess.Agent:
		err = fmt.Errorf("pane %s runs agent %s, not %s", sess.Pane, st.Agent, sess.Agent)
	}
	if err != nil {
		w.Log.Error(sess.ID, err)
		return
	}
	w.Log.Clear(sess.ID)
	if st.Status != "idle" {
		p.working()
		return
	}
	if p.idleSince.IsZero() {
		p.idleSince = now
	}
	if st.Focused {
		p.lastFocus = now
	}
	screen, ok := w.read(sess, p, now)
	if !ok {
		return
	}
	sc := c.Read(screen, now)
	if sc.Draft != "" {
		p.lastDraft = now
	}
	w.noteLimit(sess, p, sc.Limit, now)
	if now.Before(fileLimit) || p.limited(now) {
		p.idleSince = now // the idle clock restarts when the limit ends
		return
	}
	if st.Focused || sc.Draft != "" {
		return
	}
	if w.resume(sess, p, c, now) {
		return
	}
	if sess.BoundaryNote != "" {
		w.compact(sess)
		return
	}
	w.hint(sess, p, now)
}

package worker

import (
	"context"
	"time"
)

// CheckEvery is how often the loop re-resolves its binary (R-WRK-009).
const CheckEvery = time.Minute

// Loop runs Pass every Interval and asks Binary for the installed binary's version every Check.
type Loop struct {
	Pass     func() error
	Binary   func() (string, error)
	Version  string
	Log      *Log
	Interval time.Duration
	Check    time.Duration
}

// Run passes until ctx ends (its error) or the resolved binary's version differs from Version
// (nil: exit 0, and systemd's Restart=always brings the new binary up, R-WRK-009). A failing pass
// or check is logged once per text and never stops the loop (R-WRK-022). The first pass is immediate.
func (l *Loop) Run(ctx context.Context) error {
	tick := time.NewTicker(l.Interval)
	defer tick.Stop()
	check := time.NewTicker(l.Check)
	defer check.Stop()
	l.pass()
	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		case <-tick.C:
			l.pass()
		case <-check.C:
			v, err := l.Binary()
			if err != nil {
				l.Log.Error("binary", err)
				continue
			}
			l.Log.Clear("binary")
			if v != l.Version {
				l.Log.Action("restart", "-", "binary is now "+v+", running "+l.Version)
				return nil
			}
		}
	}
}

func (l *Loop) pass() {
	if err := l.Pass(); err != nil {
		l.Log.Error("pass", err)
		return
	}
	l.Log.Clear("pass")
}

package worker

import (
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strconv"
	"strings"
	"syscall"
)

// ErrLocked is returned by Lock when another worker of the project holds the lock (R-WRK-001).
var ErrLocked = errors.New("another worker runs for this project")

// Lock takes <dir>/worker.lock without waiting and writes this process's pid into it; the second
// worker gets ErrLocked naming the first's pid. The lock lives as long as the returned release (or
// the process). The file is never removed: unlinking a lock file races with a second opener.
func Lock(dir string) (release func(), err error) {
	path := filepath.Join(dir, "worker.lock")
	f, err := os.OpenFile(path, os.O_CREATE|os.O_RDWR, 0o600) //nolint:gosec // beside the store
	if err != nil {
		return nil, err
	}
	//nolint:gosec // an fd fits an int
	if err := syscall.Flock(int(f.Fd()), syscall.LOCK_EX|syscall.LOCK_NB); err != nil {
		pid, _ := io.ReadAll(f) //nolint:errcheck // the pid is a courtesy in the message
		return nil, errors.Join(fmt.Errorf("%w (pid %s)", ErrLocked, strings.TrimSpace(string(pid))), f.Close())
	}
	if err := f.Truncate(0); err != nil {
		return nil, errors.Join(err, f.Close())
	}
	if _, err := f.WriteAt([]byte(strconv.Itoa(os.Getpid())), 0); err != nil {
		return nil, errors.Join(err, f.Close())
	}
	return func() { _ = f.Close() }, nil //nolint:errcheck // closing drops the lock
}

	}

// Package systemd is the supervisor atom (design §2): the worker as a systemd user unit at
// ~/.config/systemd/user/ness-<project>.service, the only file ness writes outside the
// repository (R-WRK-002, §6). launchd is a later atom behind the same shape.
package systemd

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
)

// Exec runs a program; cli.SystemExec in production, a fake in tests.
type Exec func(dir, name string, args ...string) ([]byte, error)

// Supervisor installs and removes the unit through systemctl --user.
type Supervisor struct {
	Exec Exec
	Home string
}

// UnitName is the unit's name without the suffix: ness-<project>.
func UnitName(project string) string { return "ness-" + project }

// UnitPath is where the unit lives: what ness doctor parses (R-DOC-005).
func (s Supervisor) UnitPath(project string) string {
	return filepath.Join(s.Home, ".config", "systemd", "user", UnitName(project)+".service")
}

// Unit renders the unit: the binary by its absolute path, never through PATH (R-WRK-003, §16 #3);
// restarted on every exit, so the exit 0 of a version change brings the new binary up (R-WRK-009).
func Unit(project, binary, workdir string) string {
	return fmt.Sprintf(`[Unit]
Description=ness worker for %s

[Service]
ExecStart=%s worker run
WorkingDirectory=%s
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
`, project, binary, workdir)
}

// Available reports whether a systemd user session answers (R-WRK-004): running, or degraded,
// which exits 1 but still runs units.
func (s Supervisor) Available() error {
	out, err := s.Exec("", "systemctl", "--user", "is-system-running")
	state := strings.TrimSpace(string(out))
	if err != nil && state != "degraded" {
		msg := strings.Join(strings.Fields(err.Error()), " ")
		return errors.New("no systemd user session: " + msg)
	}
	return nil
}

// Install writes the unit, reloads systemd and enables and starts the unit (R-WRK-002). The
// caller checks Available first; a write here with no session would be a dead file.
func (s Supervisor) Install(project, binary, workdir string) (string, error) {
	path := s.UnitPath(project)
	if err := os.MkdirAll(filepath.Dir(path), 0o750); err != nil {
		return "", err
	}
	if err := os.WriteFile(path, []byte(Unit(project, binary, workdir)), 0o600); err != nil {
		return "", err
	}
	for _, args := range [][]string{{"daemon-reload"}, {"enable", "--now", UnitName(project)}} {
		if _, err := s.Exec("", "systemctl", append([]string{"--user"}, args...)...); err != nil {
			return "", err
		}
	}
	return path, nil
}

// Uninstall stops and disables the unit and removes its file (R-WRK-006); a unit that is not
// loaded or already gone is not an error.
func (s Supervisor) Uninstall(project string) error {
	_, _ = s.Exec("", "systemctl", "--user", "disable", "--now", UnitName(project)) //nolint:errcheck // not loaded is fine
	if err := os.Remove(s.UnitPath(project)); err != nil && !errors.Is(err, fs.ErrNotExist) {
		return err
	}
	_, err := s.Exec("", "systemctl", "--user", "daemon-reload")
	return err
}
